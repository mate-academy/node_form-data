# Form Data

## 🎮 About the Project
Implemented an app that displays an HTML form for entering expense information (date, title, and amount). Once the user submits the form, the data is received in a POST request, saved to a local `db/expense.json` file, and then returned as a well-formatted HTML page containing the JSON data.

## 🚀 Tech Stack
- **Node.js** (Backend functionality to handle file system and data storage)
- **API** (Uses a local JSON file for storing expense data)

## 🛠️ Tools & Dependencies
- **ESLint** – Ensures code quality and consistency  
- **Prettier** – Automatically formats code for readability  
- **Jest** – For testing the form validation and data handling functions  

## 📌 Features
✅ Shows a form to input expense details (date, title, amount)  
✅ Receives form data and saves it in a local `expense.json` file  
✅ Displays the stored JSON data on an HTML page with proper formatting  

## 🌐 Demo
Clone the repository, run the server, and try submitting the expense form to see the results.
